利用規約

改定日：2026年11月18日

第1条（適用）

  1. 本規約は、Ａｕｄｒｅｙ合同会社（以下「当社」といいます。）が提供するAdryのWebサイト、iOSアプリおよび関連サービス（以下「本サービス」といいます。）の利用条件を定めます。
  2. ユーザーは、本規約、プライバシーポリシー、データの取り扱いとAIについて、およびコミュニティガイドラインを確認して本サービスを利用します。本改定は、公開後にユーザーが本規約に同意した時点から当該ユーザーに適用します。

第2条（利用登録・Adry IDとAccount）

  1. ユーザーは、当社所定の方法で登録し、LINE、Google、Apple等の外部アカウントを利用することができます。ログイン情報を適切に管理し、Adry IDの売買、譲渡、貸与、不正利用をしてはなりません。
  2. 初回登録時に1件のAccountを作成します。Accountの追加作成は提供していません。既存のAccountは引き続き利用・切替できます。表示名、投稿、フォロー、Boardのキープ等は本サービスの設定に従います。Adry IDやAccountを利用して制限を回避したり、他者になりすましたりしてはなりません。
  3. 退会時はAdry IDを論理削除（無効化）します。論理削除はすべての保存データの即時物理削除を意味せず、保存と削除はプライバシーポリシー等に従います。
  4. 本サービスでは、ログイン・登録の単位をAdry ID、切り替えて利用するプロフィールをAccount（旧称Kao）、投稿をPost（旧称Chapter）、投稿やニュースをまとめる場をBoard（旧称Table）と呼びます。関連文書や過去の表示に旧称が残る場合も、文脈に応じて同じ対象を指します。

第3条（投稿コンテンツの取り扱いと著作権）

  1. Post、作品（Works。文章、音声、映像、画像、仕様、イベント情報等を含みます。）、引用、コメント、返信、メモ等の投稿コンテンツの著作権は、ユーザー自身または元の権利者に留保されます。ユーザーは、投稿・引用する内容について必要な権利と許諾を確保してください。
  2. ユーザーは、当社に対し、本サービスの提供、維持、改善（AI解析を含みますが、基盤モデルの学習目的を除きます）、配信、表示、バックアップのために必要な範囲で、投稿コンテンツを複製、翻案、公衆送信等する非独占的な権利を無償で許諾します。
  3. 当社が投稿コンテンツを本サービス外の広告やApp Storeスクリーンショット等に利用する場合は、原則として個別の許諾を得ます。外部記事へのリンクやAIによる要約の表示は、元の記事・画像の権利をユーザーまたは当社へ移転するものではありません。

第4条（禁止事項と安全対策）

  1. 法令、公序良俗に反する行為、犯罪、詐欺、不正アクセス、サービスの妨害、当社・他者の知的財産権、プライバシー、名誉を侵害する行為、なりすまし、嫌がらせ、差別やヘイトスピーチを禁止します。
  2. 未成年者の性的搾取、同意のない性的画像、リベンジポルノ、性的サービスへの勧誘を含む投稿を禁止します。露骨な性的・ポルノコンテンツも禁止します。ただし、医療、教育、報道、芸術等の正当な文脈を当社が認める表現を除きます。
  3. 当社は、通報、権利侵害、安全性または不正利用の確認に基づき、表示や共有の制限、投稿の削除、機能やAdry IDの停止等を行う場合があります。Webとアプリでは安全性に応じて表示範囲が異なることがあります。法令に基づく要請等に応じ、関係機関へ必要な協力を行う場合があります。

第5条（免責と損害賠償の上限）

  1. 当社は、本サービス、AI生成内容、収集したニュース、外部リンク先について、正確性、完全性、最新性、特定目的への適合性、継続提供を保証しません。ユーザーは原典や必要な情報を確認して判断してください。
  2. 当社が損害賠償責任を負う場合、有料利用者については損害発生月以前の直近12か月間に当社へ支払った利用料金の合計額を上限とします。無料利用者については適用法令が許容する範囲で責任を制限します。ただし、当社の故意または重大な過失による損害や、消費者契約法その他の強行法規により制限できない責任には、この制限を適用しません。

第6条（AI解析・生成と保存済みデータ）

  1. 本サービスは、ニュースの要約、投稿の解析、Boardの作成・振り分け、表示順の調整等にAIを利用します。処理に必要な範囲で、投稿本文、画像、リンク、プロフィール、選択中のAccount・Board、直前の閲覧・操作やキープ等の文脈を当社サーバーおよび外部AI APIへ送信する場合があります。
  2. AIの分類や生成内容には誤り、不完全さ、意図と異なる結果が含まれる場合があります。AIは医療、法律、金融その他の専門的な助言やユーザーの判断を代替しません。AI処理があることによって、閲覧制限された投稿や内部解析情報が他のユーザーへ公開されるわけではありません。
  3. 当社は、投稿コンテンツを当社または外部AI事業者の基盤モデルの学習目的に利用しません。データの取り扱いは、プライバシーポリシーおよび「データの取り扱いとAIについて」に従います。
  4. 提供を終了した機能や非表示の機能に保存された入力、AIの応答、補足情報、訂正・報告等は、サービスの維持、品質・安全性の検証、不具合対応、本人による編集・削除、権限確認、不正利用対応等に必要な範囲で取り扱います。画面上の非表示や表示期間の終了は、保存情報の削除や機能の再提供を意味しません。
  5. 保存済みの補足投稿は、利用者向けの表示ではAdry ID・Accountと結び付けない場合があります。当社は本人による編集・削除、権限確認、不正利用対応等のため、投稿とAdry IDの対応情報を別に管理します。本文に本人を特定できる情報が含まれる場合の匿名性は保証されません。

第7条（公開範囲・共有・引用）

  1. 公開条件を満たすAccount、Board、Postおよび公開メモ等は、共有リンクを通じて未ログインの人も閲覧でき、検索エンジンやリンクプレビューに表示される場合があります。投稿前にAccountのフォロー必須設定等の公開条件を確認してください。
  2. 引用や共有では、元の投稿の閲覧制限、削除、安全性の判定に応じて、元の本文・画像等が表示されない場合があります。引用・共有の操作によって元の投稿の閲覧制限を解除することはできません。
  3. 本サービス上の公開範囲を変更したり投稿を削除したりしても、第三者が既に保存した内容や検索・プレビューのキャッシュが直ちに消えることは保証できません。
  4. 保存済みの補足情報や関連Postへのリンク等も、対象のPost・Boardの閲覧条件に従います。公開条件を満たす情報は、匿名の投稿を含め未ログインのWebでも閲覧できる場合があります。匿名表示は非公開を意味しません。
  5. 作品には下書きと公開の状態があります。下書きは他のユーザーへの公開対象ではありません。公開に設定され、必要な検査と公開条件を満たした作品は、公開カタログ、共有リンク等から未ログインの人も閲覧でき、検索エンジンやリンクプレビューに表示される場合があります。
  6. 他のユーザーは、公開条件を満たす作品の作者名、作品名、カバー等を含む参照カードをPostに添付し、作品へのリンクを共有できる場合があります。この添付や共有は、作品の著作権の移転や、作品ファイルの無断転載・再配布を許諾するものではありません。
  7. 作品の編集、下書きへの変更、削除、運営による表示制限等に応じて、公開カタログや参照カードの表示を更新・制限する場合があります。検査や反映に時間がかかる場合があり、すべての表示先や第三者が保存した内容が直ちに更新・消去されることは保証しません。

第8条（Accountフォローとハイライト）

  1. Accountのフォローに伴い、フォロー先のAccountが閲覧したPost等がハイライトとしてフォローしているユーザーへ表示される場合があります。ハイライトの閲覧、コメント、リアクション等の記録は、機能の範囲内で関係するAccountへ表示される場合があります。
  2. ハイライトは原則24時間の表示・反応受付期間を持ち、旧データや提供条件により異なる場合があります。表示期間の終了は関連するすべてのデータの即時削除を意味しません。元のPostの閲覧制限、フォロー解除、ミュート等の適用条件に従います。

第9条（Boardのキープと自動キープ・解除）

  1. BoardのキープはAccountごとに管理します。自動キープ・解除をオンにしている場合、Boardの閲覧、投稿、リアクション、コメント等の利用状況に基づき、Boardを自動でキープしたりキープを解除したりします。結果は本サービスの通知一覧で確認できます。
  2. 新規登録時は自動キープ・解除をオンで開始します。既存ユーザーで設定がない場合はオフとして扱います。ユーザーは設定を変更でき、オフの場合は自動キープ・解除を実行しません。オフにしても、表示順の調整等に用いる利用状況の記録すべてが停止するわけではありません。
  3. この自動処理は、ユーザー自身がオーナーであるBoardの削除やオーナー権限の放棄を行うものではありません。オーナーによる収集元の設定、Boardの管理・削除等は、それぞれの操作と確認条件に従います。

第10条（ニュースの自動収集と収集元）

  1. 本サービスは、外部の公開記事等を取得し、関連するBoardへニュースの要約、リンク等を配信する場合があります。記事・画像の権利は元の権利者に留保されます。内容や公開日時等を確認する場合は元の記事を参照してください。
  2. 収集元を追加する権限を持つユーザーは、対象サイトの利用規約や権利条件において自動収集が禁止されていないことを確認し、収集元の利用条件に同意したうえで申請してください。申請の受付や自動判定の成功は、第三者からの利用許諾や権利上の適法性を保証しません。
  3. アクセス制限の回避、非公開ページや認証が必要な内容の収集、対象外サービスの登録をしてはなりません。当社は、サイト側のアクセス方針、権利侵害、安全性、取得失敗等により、申請の保留・拒否や収集の停止を行う場合があります。
  4. 収集件数、確認回数、取得頻度等には画面に示す上限があります。サイトの変更や取得・判定の失敗等により配信されない場合があり、自動修復や再確認による復旧を保証しません。

第11条（利用状況の記録と表示の調整）

  1. 当社は、Postの閲覧・表示時間、既読、Boardへの訪問、キープ・解除、投稿、コメント、リアクション、共有リンクの操作等を記録・解析し、おすすめ、表示順、既読・未読の扱い、自動キープ、品質・安全性の検証、継続利用の分析、不具合対応に利用します。
  2. 未ログインの公開Webでも、ブラウザに保存する匿名識別子やセッション識別子等を用いて閲覧・操作を計測する場合があります。これはユーザーのAdry IDを自動作成するものではありません。取得情報、外部送信、保存と削除はプライバシーポリシー等に従います。
  3. 表示順やAIによる振り分けは利用状況と提供条件に応じて変わります。特定の順位、配信先、収集件数、通知の到達を保証するものではありません。
  4. 保存済みの補足情報に関する閲覧、投稿・編集・削除、反応、関連情報への接続、生成依頼等の記録は、通知、利用条件の管理、品質・安全性の検証等に必要な範囲で取り扱います。本人向けの履歴と他の利用者へ表示する情報は区別して管理します。

  2. 法令上必要な場合や当社が個別の同意を求める場合には、変更後の規約への同意を確認します。旧版への同意だけで新版への同意があったものとして扱いません。
